# 🚀 Awesome LLM Apps & AI Agents

> **A curated collection of production-ready Large Language Model (LLM) applications, RAG tutorials, Model Context Protocol (MCP) agents, and voice AI workflows.**

---

## 📚 Repository Modules

- 🤖 **`starter_ai_agents/`**: Beginner-friendly AI agent patterns built with LangChain, LlamaIndex, and OpenAI.
- ⚡ **`advanced_ai_agents/`**: Multi-agent systems, autonomous task planning, memory architectures, and function calling.
- 🔌 **`mcp_ai_agents/`**: Model Context Protocol (MCP) server integrations and tool-calling agent implementations.
- 🎙️ **`voice_ai_agents/`**: Voice-enabled conversational AI agents with real-time speech synthesis and STT pipelines.
- 🔍 **`rag_tutorials/`**: Advanced Retrieval-Augmented Generation (RAG) techniques (Hybrid search, re-ranking, vector databases).
- 🎓 **`ai_agent_framework_crash_course/`**: Hands-on guides and code walkthroughs for building production AI agents.
- 🛠️ **`awesome_agent_skills/`**: Pre-built tools, web scrapers, API integrations, and agent skills.

---

## 🛠️ Tech Stack

- **Languages**: Python 3.10+, TypeScript
- **Frameworks**: LangChain, LlamaIndex, AutoGen, CrewAI, OpenAI SDK, Anthropic SDK
- **Vector DBs**: ChromaDB, Pinecone, Qdrant, FAISS

---

## 🚀 Quick Start

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Omkar4812x/Awesome-LLM-Apps.git
   cd Awesome-LLM-Apps
   ```

2. **Set up Virtual Environment**:
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

3. **Explore Tutorials**:
   Navigate into any module directory (e.g. `cd starter_ai_agents`) and run the example scripts.
